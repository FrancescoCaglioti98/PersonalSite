## 🏠 HomeLab

Il mio laboratorio casalingo dove sperimento con self-hosting, automazione e servizi personali.

**Tech Stack:** Proxmox, Docker, Tailscale, Nginx Proxy Manager, HomeAssistant

**Servizi principali:**

- Vikunja per il task management

## 🌐 Questo Sito Personale

Il mio sito personale e blog, un work-in-progress continuo dove sperimento nuove funzionalità e miglioramenti.

**Tech Stack:** Hugo, Blowfish Theme, Tailwind CSS, Cloudflare Workers

**Features:**
- Bilingue (Italiano/Inglese)
- Dark mode automatica
- Analytics con Umami
- Deploy automatico via GitHub Actions

**Cosa sto aggiungendo:**
- Pagina Uses (questa!)
- Sezione progetti
- Miglioramenti SEO
- Cross-linking tra articoli

## 🔗 Integrazione Office365 Graph API

Integrazione delle Graph API di Office365 per la gestione email e calendari in un gestionale aziendale.

**Tech Stack:** PHP, Microsoft Graph API, OAuth2

**Features:**
- Invio email tramite Outlook
- Sincronizzazione eventi calendario
- Gestione contatti
- Notifiche in tempo reale

**Risultati:**
- Unificazione della comunicazione
- Riduzione switching tra app
- Migliore tracciabilità
